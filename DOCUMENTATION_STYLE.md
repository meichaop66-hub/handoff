# Markdown Presentation Baseline v1.0

## Structure
- Use descriptive headings with a coherent hierarchy; do not skip heading levels.
- Use one blank line before and after headings and one blank line between blocks.
- Avoid repeated empty lines, trailing whitespace, and decorative emoji heading prefixes.
- Use ordered lists for sequences, unordered lists for peers, and tables for repeated field/value comparisons.

## Readability and emphasis
- Keep paragraphs focused on one idea.
- Use bold for key terms and action labels, not whole paragraphs.
- Use blockquotes for cautions and scope boundaries.
- Use fenced code blocks for commands, schemas, and copyable templates.

## Preservation
- Preserve domain-specific meaning, archived content, and executable examples.
- Do not invent metadata or change a document's status to make it look uniform.
